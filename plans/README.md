# Plans

Feature plans live here, one folder per feature:

- `plan.md` — the current scope, decisions, design, and acceptance criteria.
- `tasks.md` — ordered implementation checklist; update it as work lands.
- `changes.md` — append-only log of developer-requested plan changes and
  refinements. Keep the initial-plan baseline at the top, then add entries as
  scope or decisions change. Do not rewrite history to match the latest plan.

Keep plans in sync with the code. If a decision changes during implementation,
update `plan.md`/`tasks.md` and add an entry to `changes.md` in the same change.
